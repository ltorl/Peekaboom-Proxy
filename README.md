# Peekaboom-Proxy
Extremely compatible proxy that serves any public website so it can be embedded in an iframe. Includes rewriter.

## How to run
```
git clone https://github.com/ltorl/Peekaboom-Proxy.git && cd peekaboom-proxy && node index.js && open http://localhost:8787 &
```


#### Remotely (No Download)
```
curl -sL https://cdn.jsdelivr.net/gh/ltorl/Peekaboom-Proxy/index.js | node
```



Node js install shorcuts:

windows:
```
winget install -e --id OpenJS.NodeJS
```

mac:
```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```
